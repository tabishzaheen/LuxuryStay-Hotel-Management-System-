# LuxuryStay HMS — Frontend

React + Vite frontend for the LuxuryStay Hotel Management System.

## Run

```bash
npm install
npm run dev
```

The frontend expects the backend at `http://localhost:5000/api` by default. Set `VITE_API_URL` in `.env` if needed.
